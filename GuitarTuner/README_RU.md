# Guitar Tuner — первая версия

Простое Android-приложение для настройки гитары через микрофон. Стандартный строй: E2, A2, D3, G3, B3, E4.

## Как получить APK без Android Studio

1. Создайте репозиторий на GitHub и загрузите в него содержимое этой папки.
2. Откройте вкладку **Actions** в репозитории.
3. Выберите **Build Android APK** → **Run workflow**.
4. Когда сборка закончится, откройте завершённый запуск и скачайте артефакт **Guitar-Tuner-debug-apk**.
5. Распакуйте ZIP на телефоне и установите `app-debug.apk`. При необходимости разрешите установку приложений из браузера/файлового менеджера.
6. Запустите Guitar Tuner и разрешите доступ к микрофону.

## Что важно

- Это debug APK для личной установки, не подписанная релизная версия для Google Play.
- Тюнер использует простой алгоритм автокорреляции; шум, сильные обертоны и одновременное звучание нескольких струн могут давать ошибку.
- Настраивайте по одной струне в тихом помещении.
- Для воспроизведения точных нот и более устойчивой работы алгоритм можно улучшить в следующих версиях.
